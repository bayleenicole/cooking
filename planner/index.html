Connect GitHub

Your recipes, edits and history are kept privately on GitHub. Paste your GitHub key once on each computer or phone you use the planner on.

How to make a key
  1. Signed in to GitHub as bayleenicole, open github.com/settings/personal-access-tokens/new
  2. Token name: Recipe planner. Expiration: 1 year (or longer).
  3. Repository access: Only select repositories → pick recipes and cooking.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it, and paste it below.
